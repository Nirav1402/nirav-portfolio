# Nirav H. Acharya Portfolio

Classic editorial portfolio for Nirav H. Acharya, an AI/ML developer focused on Python, LLM applications, RAG systems, Django, FastAPI, and full-stack products.

## Run locally

```bash
npm install
npm run dev
```

The development site runs at `http://localhost:5173`.

## Production build

```bash
npm run lint
npm run build
npm run preview
```

Deploy the generated `dist` directory to any static host such as Netlify, Vercel, GitHub Pages, or Cloudflare Pages. The site has no backend requirement.
